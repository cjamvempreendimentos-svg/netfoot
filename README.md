# Netfoot

Site institucional da Netfoot, desenvolvido a partir das informações públicas do perfil `@netfoot_ba`.

## Escopo

- páginas separadas para início, calçados, perfumaria, história e atendimento;
- atendimento encaminhado ao link oficial publicado na bio;
- layout responsivo;
- informações de estoque e preços não são inventadas;
- imagem principal ilustrativa gerada para o protótipo.

## Executar localmente

Abra `index.html` no navegador ou execute um servidor estático.

## Pendências comerciais

Antes da publicação em produção, confirmar com a Netfoot:

- WhatsApp final;
- endereço completo e horários;
- marcas, categorias e disponibilidade;
- fotografias originais;
- identidade visual oficial e autorização de uso.
